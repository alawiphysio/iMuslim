# مواقيت أحمد 🕋

تطبيق أندرويد لمواقيت الصلاة، مصمم لجوال Samsung Galaxy Fold.

## المميزات
- حساب الأوقات بطريقة **تقويم أم القرى** (الفجر 18.5°، العشاء بعد المغرب بـ 90 دقيقة، و120 دقيقة في رمضان تلقائياً)
- تحديد الموقع تلقائياً: الأوقات تتغير حسب المدينة اللي أنت فيها، والافتراضي مكة المكرمة
- **صوت الأذان** وقت كل صلاة، وتقدر تختار ملف أذان MP3 من جوالك
- **تنبيه قبل الأذان** (10 دقائق افتراضياً، وتقدر تغيّرها)
- **تنبيه الإقامة** لكل صلاة (الفجر 25، المغرب 10، والباقي 20 دقيقة، وتقدر تغيّرها)
- تشغيل أو إيقاف الأذان لكل صلاة لحالها
- تعديل يدوي ± دقائق عشان تطابق مسجدك
- **ويدجت** للشاشة الرئيسية فيها الصلاة القادمة وعدّاد تنازلي وأوقات اليوم والتاريخ الهجري
- يوم الجمعة يطلع «الجمعة» بدل «الظهر»
- يرجع يجدول التنبيهات بعد إعادة تشغيل الجوال

## البناء
كل ما ترفع تعديل على فرع `main`، GitHub Actions يبني ملف APK وينشره في **Releases**.

## التثبيت
1. افتح صفحة المستودع ← Releases ← حمّل `MawaqitAhmed.apk`
2. اسمح بتثبيت التطبيقات من مصادر غير معروفة
3. افتح التطبيق ووافق على الإشعارات والموقع
4. اضغط «استثناء من توفير البطارية» واختر **غير مقيّد** (مهم في سامسونج)
5. اختر ملف الأذان من «اختيار ملف الأذان»
6. أضف الويدجت: اضغط مطوّلاً على الشاشة ← الأدوات ← مواقيت أحمد
